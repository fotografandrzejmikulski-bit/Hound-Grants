# Security Policy

HOUND is an evaluation project and should be operated under a strict synthetic-environment security model.

## Supported scope

Report vulnerabilities affecting:

- sandbox isolation;
- evaluator integrity;
- event-log integrity;
- unauthorized network egress;
- credential exposure;
- data leakage;
- unsafe repository automation.

## Out of scope

Do not submit real-world targets, stolen credentials, private personal data, or operational exploitation instructions as benchmark material.

## Reporting

Until a dedicated project security contact is added, security issues should be reported privately to the project maintainer rather than disclosed with working exploit details in a public issue.
