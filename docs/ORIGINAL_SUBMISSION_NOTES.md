# Original Submission Notes

This repository originated from a supplied grant draft. The original draft is preserved in the conversation source material; this repository version is a structured, evidence-controlled adaptation.

## Author-supplied project thesis

The supplied draft argues that outcome-only agent evaluation can miss unsafe procedural shortcuts in stateful, high-risk environments. HOUND proposes execution-grounded evaluation with explicit policy constraints, trajectory logging, and metrics separating technical success from compliance.

## Editorial changes made for grant readiness

- Strong absolute novelty language is replaced with defensible proposal language.
- Externally verifiable claims are tracked separately from HOUND's own definitions and projections.
- Program-specific benefits are treated as unverified until official terms are confirmed.
- The proposal avoids asserting that a metric reveals an agent's intent or mental state.
- Safety controls explicitly prohibit production targets, real credentials, and real personal data in benchmark runs.
- Author contact information has been added to a dedicated file rather than scattered through the proposal.

## Important source-grounding rule

No factual claim should be promoted from the original draft to “verified” merely because it appears in that draft. The claims register controls the evidentiary status of external facts.
