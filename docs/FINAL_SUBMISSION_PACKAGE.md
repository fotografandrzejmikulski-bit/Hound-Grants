## Submission thesis

HOUND proposes an execution-grounded benchmark for long-horizon AI agents operating under explicit procedural, authorization, provenance, and approval constraints. The project measures not only whether an agent succeeds, but whether it reaches success through an operationally acceptable trajectory.

## Evidence standard

The package distinguishes:

- established external facts;
- project-defined metrics and architecture;
- research hypotheses;
- future deliverables and projections.

No empirical result is claimed unless it has actually been measured. No program benefit is treated as guaranteed unless the applicable program documentation supports it.

## Research contribution

The project will empirically test a state-first, deterministic-first, attribution-oriented evaluation design against relevant baselines. The contribution is the experimentally validated combination of execution telemetry, state invariants, policy constraints, model/scaffold controls, and causal failure attribution — not an unsupported claim of first use of procedural compliance metrics.

## Technical evidence currently in repository

The repository contains an executable Python foundation, deterministic metric tests, a synthetic stateful environment, mediated services, a benchmark orchestration layer, a versioned public scenario manifest, and public scenarios across four domains.

## Research deliverables

The full funded work will extend this foundation to hardened isolation, external model adapters, held-out evaluation, expert calibration, large-scale scenario authoring, statistical analysis, and a reproducibility release.

## Non-negotiable safety constraints

Benchmark execution remains synthetic by default. No real credentials, production financial systems, real personal data, or unauthorized external targets are required by the research design.

## Final applicant statement

The applicant seeks support to turn the executable foundation into a rigorously validated benchmark whose results can be independently inspected, reproduced, challenged, and compared with existing agent-evaluation methods.
