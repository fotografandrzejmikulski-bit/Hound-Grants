# HOUND Documentation

This directory contains the research, methodology, governance, and release controls for the HOUND benchmark proposal.

## Core documents

- `GRANT_PROPOSAL.md` — canonical grant narrative.
- `METHODOLOGY.md` — benchmark design and scoring.
- `IMPLEMENTATION_PLAN.md` — engineering architecture and work packages.
- `EVALUATION_PROTOCOL.md` — standardized experimental procedure.
- `RISK_AND_GOVERNANCE.md` — safety and governance framework.
- `ETHICS.md` — ethical and dual-use boundaries.
- `REPRODUCIBILITY.md` — publication and reproducibility standard.
- `DATA_CARD.md` — scenario/data documentation.
- `MODEL_CARD.md` — evaluated model/scaffold configuration template.
- `CLAIMS_REGISTER.md` — factual-claim verification control.

## Submission-critical note

The original source material contains a mixture of research claims, projections, current-market assertions, and program-specific assumptions. `CLAIMS_REGISTER.md` is the mandatory control that prevents these categories from being conflated in an external grant submission.
